RULES
Folder · <storage>/localanime/<Title>/, one per show.
Episodes · mp4, mkv, webm; number from the file name (“Show - 03.mkv” → EP 3, else file order).
Subtitles · a .srt / .ass with the same base name is a subtitle track.
Cover, details · optional cover.jpg and details.json (same keys as local manga).
No cover · first frame of episode 1 (AY9 preview store), else the plain tile.
Plays · offline in the same player; nothing is downloaded or uploaded.
