# N31 accessibility audit of Tsuzuki UI

Scope: `presentation/tsuzuki/**`, `presentation/theme/tsuzuki/**`, `tachiyomi/ui/tsuzuki/**` (108 Kotlin files). No upstream files were edited and no visuals or behaviour changed apart from the 2 dp layout growth noted below.

Already fine (no change): pills and segments use `Role.Tab` / `selectable`, the Media switch uses `selectable`, most Switch/Checkbox/Radio rows use `toggleable` with `onCheckedChange = null`, `IconButton`s already carry descriptions, decorative icons next to a text label correctly keep `contentDescription = null`.

New strings (all 8 locales: base, ja, zh-rCN, ko, es, pt-rBR, fr, de): `tsz_a11y_back`, `tsz_a11y_decrease`, `tsz_a11y_increase`, `tsz_a11y_clear`, `tsz_a11y_startup`. Existing `action_close` and `action_delete` reused.

## 1. Icon-only controls without a localised description (13 fixes)
- `TsuzukiBookNotes`, `TsuzukiAboutScreen`, `TsuzukiSourcePriority`, `TsuzukiAppLanguage`, `TsuzukiSettingsMain`: back circle icon `null` -> `tsz_a11y_back` (5).
- `TsuzukiNewUpdateScreen`: close circle `null` -> `action_close`.
- `TsuzukiStatsScreen`: goal -/+ `RoundButton` gets a description parameter (`tsz_a11y_decrease` / `tsz_a11y_increase`) (2).
- `TsuzukiSourcePriority`: -/+ `StepButton` descriptions (2).
- `TsuzukiDuplicateFinder`: search-field clear button `null` -> `tsz_a11y_clear`.
- `TsuzukiFontItem`: hardcoded "Delete" -> `action_delete`.

## 2. Hardcoded English (1 fix, plus the Delete above)
- `TsuzukiStartup`: "Tsuzuki is starting. Tap to skip." -> `tsz_a11y_startup`.
- Left as is: the app name "Tsuzuki" (brand; `TsuzukiNav` logo, About title), URL placeholders `https://`.

## 3. Touch targets under 48 dp (8 fixes, `minimumInteractiveComponentSize()`)
Back/close circles (44 dp) in BookNotes, About, SourcePriority, AppLanguage, SettingsMain, NewUpdate; Stats `RoundButton` (44 dp); Home `IconCircle` (44 dp); DuplicateFinder `RoundButton` (44 dp); SourcePriority `StepButton` (40 dp). The drawn circle keeps its size; the layout box grows to 48 dp (up to 4 dp of extra spacing around these buttons).
- Not changed: `MediaSwitch` tabs on Home (about 36 dp tall inside a bordered pill; growing them would change the visual), reader contents `ChapterRow` (46 dp). Compose's pointer input already expands both to the 48 dp touch minimum.

## 4. Missing semantics (7 role fixes + 6 switch labels + 17 headings)
- `Role.Button` added: `TsuzukiChapterFilterSheet` (scanlator row), `TsuzukiHistoryItem`, `TsuzukiAboutScreen` (version, privacy policy), `TsuzukiReaderContents` (chapter row), `TsuzukiBrowse` (pinned source tile), `TsuzukiMixedLibraryGrid` (book tile) (7).
- Unlabelled `Switch` got `contentDescription` of its row label: `TsuzukiDownloadSheet`, `TsuzukiReaderSettingsSheet`, `TsuzukiReplaceRules` (option switch and rule switch, rule title), `TsuzukiReaderStatusBarSettings`, `TsuzukiExtensionStoreItem` (store name) (6).
- `semantics { heading() }` on screen/sheet/dialog titles: CatalogueFilters, ExtensionDetailsHeader, BookNotes, ChapterFilterSheet, ChapterSearch, DownloadSheet, DuplicateMangaDialog, Notebook, LibraryQueries, About, More, NewUpdate, DuplicateFinder, ReaderContents, SourcePriority, AppLanguage, SettingsMain (17). Number-only display texts (queue count, stats) are not headings.

## Not done
- Contents-drawer scrim (`TsuzukiReaderContents`) is an unlabelled full-screen click target; left alone since BACK and the close action already dismiss it.
- No device/TalkBack run (task forbids adb); results are from reading the code, build and unit tests.
